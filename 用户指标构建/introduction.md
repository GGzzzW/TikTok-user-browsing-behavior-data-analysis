# 抖音用户数据分析

## 1. 项目介绍

本项目以抖音用户的浏览行为记录为基础，从用户、作者和作品三个角度进行数据分析，并在此基础上构建相关特征指标。

每条数据代表一次由用户主动发起的浏览行为，记录了用户与创作者作品之间的交互信息，包括观看对象、作品属性、发布信息、观看结果和点赞情况等。

## 2. 数据集说明

数据集包含以下 13 个有效字段：

| 字段名 | 含义 |
| --- | --- |
| `uid` | 用户 ID |
| `user_city` | 用户城市 |
| `item_id` | 作品 ID |
| `author_id` | 作者 ID |
| `item_city` | 作品发布城市 |
| `channel` | 作品频道 |
| `finish` | 是否完整观看 |
| `like` | 是否点赞 |
| `music_id` | 音乐 ID |
| `duration_time` | 作品时长 |
| `real_time` | 具体发布时间 |
| `H` | 发布小时 |
| `date` | 发布日期 |

## 3. 浏览行为描述

一条浏览行为记录主要回答以下问题：

- **什么人观看**：通过用户 ID 和用户城市描述用户信息；
- **观看了谁的作品**：通过作者 ID 标识作品的创作者；
- **观看了什么作品**：包含作品 ID、作品城市、背景音乐及作品时长；
- **通过什么渠道观看**：由作品频道字段记录；
- **是否完整观看**：由完整观看字段记录；
- **是否点赞**：由点赞字段记录；
- **作品何时发布**：包含具体发布时间、发布日期和发布小时。

## 4. 数据分类

根据字段的业务含义，可以将数据划分为以下四类：

| 分类 | 包含字段 |
| --- | --- |
| 用户信息 | `uid`、`user_city` |
| 作者信息 | `author_id` |
| 作品信息 | `item_id`、`item_city`、`channel`、`music_id`、`duration_time`、`real_time`、`H`、`date` |
| 浏览行为 | `finish`、`like` |

## 5. 分析对象

从浏览行为中可以抽象出用户、作者、作品、音乐和城市等实体。本项目主要从以下三个角度展开分析：

1. **用户角度**：分析用户的浏览量、点赞量、观看作者数、观看作品数和完整观看情况等；
2. **作者角度**：分析作者作品获得的浏览量、点赞量、完整观看量和作品数量等；
3. **作品角度**：分析作品的浏览量、点赞量、发布城市和背景音乐等。

后续将在完成数据清洗的基础上，使用 SQL 构建上述对象的特征指标，并为数据可视化和进一步的数据挖掘提供支持。
